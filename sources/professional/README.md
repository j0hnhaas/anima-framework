# Pillar: professional

Codes, guidelines and statements of professional bodies of psychologists. Bindingness: `professional` – binding for members where a code has been adopted, otherwise good practice.

> **Status:** candidate sources, **to be verified**. Check the current version of each code and search for specific statements or guidance on AI.

**Note on "APA":** in ANIMA, APA always means the **American Psychological Association**, not the American Psychiatric Association. Psychiatric bodies are out of scope (see [scope](../../docs/scope.md#boundary-to-psychotherapy-and-psychiatry)).

## Reuse

Codes of professional bodies are usually protected by copyright. Summarise them in your own words, quote only short passages and link to the original.
