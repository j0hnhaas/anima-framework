# Data

Machine-readable versions of the framework, generated by `scripts/build.py`:

- `navigator.json` – all sources and requirements
- `navigator.csv` – one row per requirement

All files in this folder are licensed under [CC0 1.0](../LICENSES/CC0-1.0.txt), so they can be reused in other tools without restrictions.

The field definitions are described in [`navigator/README.md`](../navigator/README.md).
