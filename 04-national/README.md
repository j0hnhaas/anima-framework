# Layer 4 – National law

One folder per country, named with the ISO 3166-1 alpha-2 code (e.g. `at`, `de`, `ch`).

| Country | Folder | Status |
|---|---|---|
| Austria | [`at/`](at/) | in progress |

## Adding a country

1. Create a folder with the country code.
2. Copy the structure of [`at/README.md`](at/README.md).
3. Quote the law in its original language and add an English summary.
4. Open a pull request (see [CONTRIBUTING.md](../CONTRIBUTING.md)).
